iPhone (Koder) ve Bilgisayar (VS Code) Çalıştırma Rehberi

1. iPhone'da "Koder" Uygulamasında Çalıştırma

  1. App Store'dan ücretsiz Koder Code Editor uygulamasını indirip açın.
  2. Sol üstteki "+" (Yeni Dosya) butonuna dokunun ve dosya adını index.html yapın.
  3. Bu sayfadaki tüm kodu kopyalayıp index.html içine yapıştırın ve kaydedin.
  4. Sağ alt veya üstteki "Preview" (Göz / Dünya ikonu) butonuna bastığınızda uygulama tıpkı yerel bir iOS uygulaması gibi tam ekran çalışacaktır!
  5. İpucu: Dilerseniz dosyayı iPhone'da Dosyalar (Files) uygulamasına kaydedip Safari ile açarak Paylaş ➔ Ana Ekrana Ekle diyerek telefonunuzun ana ekranına uygulama ikonu olarak da sabitleyebilirsiniz.

2. Bilgisayarda "Visual Studio Code" ile Çalıştırma

  1. Bilgisayarınızda AeroLexis adında bir klasör açıp VS Code ile içine girin.
  2. index.html adında bir dosya oluşturup bu kodun tamamını içine yapıştırın ve Ctrl+S (veya Mac'te Cmd+S) ile kaydedin.
  3. VS Code içindeki Live Server eklentisiyle ("Go Live") veya dosyaya çift tıklayarak doğrudan Chrome/Edge/Safari üzerinde açabilirsiniz.

3. Bilgisayar ve iPhone Arasında Kelime Eşitleme

Eklediğiniz tüm kelimeler ve çalışma istatistikleriniz cihaz hafızasına (localStorage) otomatik kaydedilir. Bilgisayarda eklediğiniz yeni kelimeleri iPhone'a aktarmak için üstteki Yedekle / Aktar butonuna basıp JSON kodunu kopyalayarak iPhone'unuzda yapıştırmanız yeterlidir.
